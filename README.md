# Лента dantpro.ru для Дзена

Каждый час GitHub Actions запускает `build_feed.py`: скрипт смотрит в Тильде (проект DANT 8277548) опубликованные статьи `/blog/...`
в новом дизайне (Vibe-блок T1370), собирает полный текст и обновляет `docs/dzen.xml`. GitHub Pages отдаёт файл по адресу
`https://<логин>.github.io/dant-dzen/dzen.xml` — эту ссылку один раз подключают в Студии Дзена.

- Новая статья попадает в ленту в течение часа после публикации в Тильде и публикуется в Дзене сразу.
- 10 стартовых статей (`state.json → drafts`) уходят в Дзен черновиками: в них фото-заглушки.
- Берутся только статьи, опубликованные после `cutoff` (27.10.2026). Страницы с галкой «не включать в RSS» пропускаются.
- Статья без блока T1370 или короче 300 знаков пропускается (видно в логе Actions).
- Правки статьи в Тильде доезжают в Дзен 7 дней после первой загрузки (ограничение Дзена).

Ключ Tilda MCP хранится в секрете репозитория `TILDA_MCP_KEY`, в коде его нет.
Ручной запуск: вкладка Actions → «RSS для Дзена» → Run workflow.
